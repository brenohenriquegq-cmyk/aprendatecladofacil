APRENDA TECLADO FÁCIL

Política de Privacidade

Última atualização: 26 de setembro de 2026

Esta política descreve como o CanalDark Pipeline (“o aplicativo”) trata dados ao usar a API de Dados do YouTube. O aplicativo é uma ferramenta de uso próprio do autor do canal Aprenda Teclado Fácil: ele gera vídeos de tutorial de teclado no computador do autor e os envia ao canal do próprio autor. Não é oferecido ao público nem usado por terceiros.

Serviços de API do YouTube

O aplicativo usa os Serviços de API do YouTube. Ao usá-lo, você concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google é regido pela Política de Privacidade do Google.

Quais dados são acessados

  • Envio de vídeos (escopo youtube.upload): o aplicativo publica vídeos, com título, descrição, tags, miniatura e data de estreia, no canal autorizado.
  • Identificação do canal (escopo youtube.readonly): o aplicativo lê o nome e o identificador do canal autorizado, apenas para confirmar que está publicando no canal certo antes de cada envio.

O aplicativo não lê, coleta nem armazena dados de espectadores, comentários, mensagens, histórico, inscritos ou qualquer informação de outros usuários.

Como os dados são armazenados

O token de acesso concedido pelo Google fica gravado somente no computador do autor, em arquivo local, e é usado apenas para as ações descritas acima. Nenhum dado é enviado a servidores próprios, vendido, compartilhado com terceiros ou usado para publicidade.

Cookies

O aplicativo é um programa local e não usa cookies. Este site também não usa cookies nem ferramentas de rastreamento.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento na página de configurações de segurança do Google (permissões de apps de terceiros). Após a revogação, o aplicativo deixa de conseguir acessar o YouTube em nome da conta.

Exclusão de dados

O único dado guardado pelo aplicativo é o token de autorização, em um arquivo local no computador do autor, e não existe cópia em nenhum outro lugar. Revogado o acesso, esse token deixa de valer imediatamente, e o autor apaga o arquivo local. Dados obtidos da API (nome e identificador do canal) são usados apenas no momento do envio e não são armazenados. O aplicativo não guarda nenhum dado da API por mais de 30 dias.
